# apple-glass

An Apple-inspired look for Claude Code in the desktop and mobile apps: frosted-glass panels over a soft, slowly drifting color backdrop, rounded iMessage-style message bubbles (blue for you, light or dark cards for Claude), Apple system colors and the system font. Works in light and dark mode. The terminal and editors draw no themes, so it has no effect there.

## Install

At the prompt of a terminal session:

```
/plugin install apple-glass --marketplace jonashackenjos-eng/apple-glass
```

From a shell:

```bash
claude plugin install apple-glass --marketplace jonashackenjos-eng/apple-glass
```

Answer `y` to add the marketplace, then pick the user scope. In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `jonashackenjos-eng/apple-glass`, then Add plugin.

This repository is private: installing needs read access to it on GitHub and a git credential for github.com on your machine (an SSH key, or `gh auth login` then `gh auth setup-git`).
